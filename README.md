# Happy Birthday Lakshit Sharma (23 November)

Static mobile-first birthday web card built with vanilla HTML, CSS, and JavaScript.

## Fast Deploy to GitHub + Vercel
1. Create a new GitHub repo (e.g. `happy-birthday-lakshit`).
2. Upload `index.html` and `vercel.json` to the root of the repo.
3. Go to https://vercel.com/new, import the repo, keep **Framework Preset** as `Other`, and click **Deploy**.
